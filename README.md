# Mini SOC Lab

## Overview
 
A hands-on cybersecurity lab designed to simulate, detect and investigate suspicious authentication activity within a virtualised Linux environment.

## Objectives

- Build and configure a Linux security lab
- Understand Linux authentication and system logs
- Simulate suspicious login activity
- Detect and investigate security events
- Document findings and recommended remediation
- Develop practical SOC analyst skills
